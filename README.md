# Конфа

Русскоязычный сервис видеовстреч и вебинаров до 50 участников. Видеосвязь и запись работают через LiveKit Cloud; приложение хранит комнаты, чат и пометки в D1, готовое видео — в R2, материалы урока — в R2-привязке `FILES`.

## Настройка облачных сервисов

1. Создайте проект в [LiveKit Cloud](https://cloud.livekit.io/). Возьмите WebSocket URL проекта, API key и API secret.
2. Создайте R2 bucket в своей учётной записи Cloudflare и S3 API token с доступом Object Read & Write **только** к этому bucket. LiveKit Egress загружает видео прямо в него; сайт читает запись через S3 API R2.
3. Добавьте в настройки среды Site секреты `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`, `R2_S3_ACCESS_KEY`, `R2_S3_SECRET_KEY`. Добавьте обычные переменные `LIVEKIT_URL` (wss URL проекта), `R2_S3_ENDPOINT` (полный HTTPS S3 endpoint R2), `R2_S3_BUCKET` (имя bucket) и `PUBLIC_SITE_URL` (публичный HTTPS адрес этого Site). Секреты не кладите в исходники или `.env` под Git.
4. В R2 настройте lifecycle rule: удалять объекты с префиксом `recordings/` через 30 дней. Приложение прекращает выдавать файл точно по сроку в базе; удаление объекта самим R2 может занять до 24 часов.
5. После изменения переменных среды опубликуйте новую версию Site, чтобы они вступили в силу.

Без ключей LiveKit создание комнаты возвращает понятную ошибку; видеосвязь и запись не имитируются. Для публичного сервиса расходы LiveKit и R2 зависят от фактического использования.

### Материалы урока и конвертер PowerPoint/Word

Страницы загруженных материалов хранятся в R2-привязке `FILES` (`.openai/hosting.json`, `"r2": "FILES"`). При `wrangler dev --local --persist-to .wrangler/state` это локальное хранилище на диске (`.wrangler/state/v3/r2`) — его нужно сохранять вместе с базой. На комнату — до 20 материалов и около 300 МБ; файлы удаляются, когда конференцию заканчивают, и у комнат, где доской не пользовались две недели.

PDF и картинки превращаются в страницы прямо в браузере учителя. PowerPoint и Word (`.pptx .ppt .odp .docx .doc .odt .rtf`, до 50 МБ) сначала переводит в PDF отдельный сервис `services/convert/server.mjs` с LibreOffice:

1. Установите LibreOffice без лишнего и шрифты, совместимые по метрикам с Office: `apt-get install --no-install-recommends libreoffice-impress libreoffice-writer fonts-liberation fonts-dejavu fonts-crosextra-carlito fonts-crosextra-caladea`. Tahoma, Verdana и другие шрифты, которых нет на сервере, заменяются похожими, поэтому вёрстка слайдов может немного сдвинуться. На машине с 2 ГБ памяти добавьте swap.
2. Скопируйте `services/convert/server.mjs` в `/opt/konfa-convert/`, задайте `CONVERT_SECRET` (длинная случайная строка) в `/etc/konfa-convert.env` с правами 600, установите `deploy/konfa-convert.service` в `/etc/systemd/system/` и выполните `systemctl enable --now konfa-convert`. Юнит ограничивает LibreOffice: только localhost, без доступа к приложению и его секретам, одна конвертация за раз, низкий приоритет CPU и памяти.
3. Добавьте в переменные среды сайта `CONVERTER_URL=http://127.0.0.1:8790/convert` и `CONVERTER_SECRET` с тем же значением.

Без конвертера PDF и картинки работают, а для PowerPoint и Word учитель видит просьбу сохранить файл как PDF.

## Локальная разработка

```powershell
pnpm install
node node_modules/drizzle-kit/bin.cjs generate
node scripts/run-framework.mjs build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_fuzzy_ozymandias.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_petite_mentallo.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_careful_overlord.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0003_bent_rattler.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0004_fuzzy_scarecrow.sql
node scripts/run-framework.mjs dev
```

Для уже созданной базы примените только ещё не выполненные миграции (`0001_petite_mentallo.sql`, `0002_careful_overlord.sql`, `0003_bent_rattler.sql`, `0004_fuzzy_scarecrow.sql`). Миграции `0003` (доска учителя) и `0004` (прокрутка доски и материалов) примените до выкладки новой версии: без их таблиц и колонок комната не загрузится; прежней версии они не мешают. Пометки, указка и окно пометок хранятся в уже существующих таблицах. Юнит-тесты: `node --test "lib/*.test.ts"`. Для локальных звонков задайте те же переменные в игнорируемом `.dev.vars` (кроме `PUBLIC_SITE_URL`, которое должно указывать на доступный Egress публичный URL; запись с localhost невозможна). Не запускайте миграции повторно после их применения.

## Сценарии

- Создатель получает отдельную ссылку ведущего с секретом во фрагменте URL. Гостям копируется ссылка без секрета.
- Встреча: каждый участник может говорить и показывать экран. Вебинар: зрители смотрят, пишут в чат, поднимают руку; ведущий приглашает на сцену.
- Пометки поверх текущей демонстрации сохраняются в D1 и рассылаются через LiveKit. Своя пометка появляется сразу, без ожидания сервера, а остальные видят штрих ещё во время рисования; если сохранить не удалось, пометка исчезает с понятным сообщением.
- Во встрече рисовать могут все. В вебинаре рисуют ведущий и выступающие на сцене, а зрителям ведущий разрешает пометки по одному кнопкой «Разрешить пометки» в списке участников. Докладчик всегда может рисовать на своём экране, стирать и двигать чужие пометки и очищать холст. Ведущий может поставить пометки участников на паузу — тогда рисуют только он и докладчик.
- Панель пометок переключает режимы «Просмотр» (пометки видны, щелчки и касания ничего не рисуют, а только двигают и масштабируют демонстрацию) и «Рисовать»: карандаш, маркер, линии и стрелки, фигуры, текст, перемещение и ластик, цвет и толщина. Указка и «Исчезающий карандаш» видны всем с именем автора и не сохраняются. Текст пишется прямо на экране и переносится по строкам одинаково у всех; щелчок по своему тексту инструментом «Текст» или двойной щелчок инструментом «Перемещение» открывает его для правки. Автор пометки виден при наведении инструментами «Перемещение», «Ластик» и «Текст», а с «Показывать авторов» (меню «Ещё» на панели) — у всех пометок. Отмена и повтор — кнопками или Ctrl+Z, Ctrl+Shift+Z и Ctrl+Y; горячие клавиши работают в любой раскладке.
- «Очистить все пометки» сначала спрашивает подтверждение; очистку, как и любое стирание, можно вернуть кнопкой «Отменить» (Ctrl+Z). В списке участников во время показа видно, сколько пометок оставил каждый, в том числе вышедшие (группа «Вышли»), а ведущий и докладчик могут стереть пометки одного участника: кнопка с ластиком, затем «Стереть N?».
- На телефоне и планшете рисуют пальцем или стилусом. Двумя пальцами демонстрацию приближают и сдвигают, а в режиме «Просмотр» двойное касание приближает и возвращает масштаб; на компьютере для этого есть кнопки масштаба, двойной щелчок в «Просмотре», Ctrl+колесо и щипок на тачпаде (Chrome, Edge, Firefox). После касания стилусом пальцы только двигают и масштабируют экран, а ладонь не рисует, пока не включено «Пальцы тоже рисуют».
- Ведущий показывает вкладку браузера, отдельное окно или весь экран и делает пометки прямо в конференции; другой участник показывает экран с разрешения ведущего. Без демонстрации область комнаты занята участниками и чатом: плитки камер одинаковые, 16:9, кадр виден целиком, и все участники помещаются без прокрутки. Во время демонстрации и при открытой доске камеры стоят лентой: над доской, а у демонстрации — сверху или слева, где кадру остаётся больше места. Сколько места отдать ленте, каждый выбирает у себя кнопками «Мелкие камеры», «Средние камеры» и «Крупные камеры» (выбор запоминается на устройстве); лента занимает не больше трети сцены, а плитки в ней встают в один или несколько рядов так, чтобы были видны все. Плитка ведущего стоит первой, своя — последней; у говорящего рамка, у выключенного микрофона значок, вместо выключенной камеры — первая буква имени. Каждая камера приходит в качестве под размер своей плитки, демонстрация экрана — всегда в полном. Любой участник может локально развернуть демонстрацию на всю область комнаты, переключать миниатюры и список участников поверх экрана или свернуть эту панель; на широком экране компьютера инструменты пометок в таком режиме находятся поверх экрана, а на телефоне, планшете и в узком окне — под ним или слева. Замена фона камеры доступна до входа и во время звонка; изображение остаётся на устройстве пользователя.
- Во время показа докладчик может открыть «Окно пометок поверх экрана» (настольные Chrome и Edge 116+, Firefox 151+): небольшое окно поверх всех окон с демонстрацией, пометками участников и указкой, в котором можно и рисовать. После выбора экрана Конфа остаётся на своей вкладке и предлагает открыть это окно. В остальных браузерах число новых пометок появляется в заголовке вкладки, пока она скрыта или не в фокусе.
- При показе всего экрана Конфа скрывает у докладчика собственную демонстрацию, чтобы участники не видели эффект зеркала; её можно показать кнопкой «Показать демонстрацию», а в окне пометок по умолчанию видны только пометки. Удобнее показывать отдельное окно или вкладку. Кнопка браузера «Поделиться этой вкладкой» меняет вкладку без остановки показа, и пометки сохраняются; после остановки и нового показа холст начинается заново.
- Рабочее пространство учителя: ведущий нажимает «Создать доску» (на телефоне — в меню «Ещё»), и у всех на месте демонстрации появляются две части — «Доска» (белая бумага в бледную клетку) и «Материалы» (PDF, PowerPoint, Word или картинка). На широком экране части стоят рядом, на узком — друг под другом. Пометки на доске и в материалах делаются теми же инструментами, что и на демонстрации, по умолчанию чёрным цветом (свой цвет для бумаги панель запоминает отдельно от цвета на демонстрации). Одна панель инструментов работает с той частью, где учитель нажимал последним (она выделена рамкой), туда же действуют Ctrl+Z и «Очистить». Кнопка в подвале затем закрывает и снова открывает доску — нарисованное и материалы сохраняются.
- Доска бесконечная: она прокручивается вниз, и ниже последней пометки всегда есть чистое место (всего до 200 экранов). Материал показан одной колонкой: все страницы или слайды идут друг под другом. Учитель прокручивает обе части колесом мыши, перетаскиванием в режиме «Просмотр» (на сенсорном экране — пальцем, с инструментом — двумя пальцами), полосой прокрутки справа и клавишами PgUp, PgDn, Пробел, стрелки, Home и End. В шапке материала — «‹ 3 / 12 ›»: стрелки ведут на соседнюю страницу, а в поле можно ввести номер страницы и нажать Enter; полоса прокрутки при перетаскивании показывает номер страницы. Кнопка «В начало доски» возвращает к верху доски. Место, где остановился учитель, запоминается для доски и для каждого материала.
- Ученики строго следуют за учителем: видят то же место доски и материала (окно учителя помещается у них целиком), сами не прокручивают, но могут приближать у себя. Запись показывает то же. Если учитель вошёл по ссылке ведущего с двух устройств (например, ноутбук и планшет для письма), ведёт то устройство, на котором он прокручивал или рисовал последним: ученики и второе устройство показывают его место.
- Карандаш, маркер, указка и ластик свободно проходят через всю доску. Линии, фигуры, текст и перемещение работают в пределах одного экрана доски (16:9); пока выбран такой инструмент, граница показана бледным пунктиром. Отмена и повтор идут по порядку действий по всей доске или материалу, и вид возвращается к месту изменения. «Очистить всю доску» стирает доску целиком у всех, возвращает всех к её началу и не отменяется (перед этим есть подтверждение); в материалах «Стереть пометки на странице» действует на текущую страницу и отменяется как обычно.
- Учитель сворачивает любую часть в полосу сбоку экрана (на узком экране — сверху или снизу) — она сворачивается у всех; если свёрнуты обе, между полосами видны камеры. Материалы загружаются через меню «Материалы» или перетаскиванием файла на эту часть; там же можно переключиться на загруженный ранее материал, закрыть или удалить его. Страницы готовятся в браузере учителя, ученики загружают только картинки тех страниц, что рядом с экраном.
- По умолчанию на доске и в материалах рисует только учитель. Кнопка «К доске» в списке участников вызывает одного ученика (у него появляется панель инструментов), «Убрать от доски» возвращает; переключатель «Все ученики рисуют» на панели доски разрешает всем. Ученик стирает и двигает только свои пометки, учитель — любые. Если одновременно идёт демонстрация экрана, каждый переключает у себя «Доска / Демонстрация»; по умолчанию показано то, что началось позже. В запись попадает то же, что на экране.
- Кнопка «Закончить конференцию» завершает комнату для всех участников.
- Ведущий вручную запускает запись. В запись попадают пометки, рисование в реальном времени и указка. Через отдельную ссылку готовое видео доступно любому, у кого есть эта ссылка, до истечения 30 дней.

Проверяйте демонстрацию, инструменты пометок и окно пометок в настольном Chrome или Edge по HTTPS. В мобильном браузере доступны просмотр демонстрации с масштабированием, пометки пальцем и стилусом, чат и поднятие руки; показ экрана и окно пометок работают только на компьютере.

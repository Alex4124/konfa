# Конфа

Русскоязычный сервис видеовстреч и вебинаров до 50 участников. Видеосвязь и запись работают через LiveKit Cloud; приложение хранит комнаты, чат и пометки в D1, готовое видео — в R2.

## Настройка облачных сервисов

1. Создайте проект в [LiveKit Cloud](https://cloud.livekit.io/). Возьмите WebSocket URL проекта, API key и API secret.
2. Создайте R2 bucket в своей учётной записи Cloudflare и S3 API token с доступом Object Read & Write **только** к этому bucket. LiveKit Egress загружает видео прямо в него; сайт читает запись через S3 API R2.
3. Добавьте в настройки среды Site секреты `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`, `R2_S3_ACCESS_KEY`, `R2_S3_SECRET_KEY`. Добавьте обычные переменные `LIVEKIT_URL` (wss URL проекта), `R2_S3_ENDPOINT` (полный HTTPS S3 endpoint R2), `R2_S3_BUCKET` (имя bucket) и `PUBLIC_SITE_URL` (публичный HTTPS адрес этого Site). Секреты не кладите в исходники или `.env` под Git.
4. В R2 настройте lifecycle rule: удалять объекты с префиксом `recordings/` через 30 дней. Приложение прекращает выдавать файл точно по сроку в базе; удаление объекта самим R2 может занять до 24 часов.
5. После изменения переменных среды опубликуйте новую версию Site, чтобы они вступили в силу.

Без ключей LiveKit создание комнаты возвращает понятную ошибку; видеосвязь и запись не имитируются. Для публичного сервиса расходы LiveKit и R2 зависят от фактического использования.

## Локальная разработка

```powershell
pnpm install
node node_modules/drizzle-kit/bin.cjs generate
node scripts/run-framework.mjs build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_fuzzy_ozymandias.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_petite_mentallo.sql
node scripts/run-framework.mjs dev
```

Для уже созданной базы примените только ещё не выполненную миграцию `0001_petite_mentallo.sql`. Для локальных звонков задайте те же переменные в игнорируемом `.dev.vars` (кроме `PUBLIC_SITE_URL`, которое должно указывать на доступный Egress публичный URL; запись с localhost невозможна). Не запускайте миграции повторно после их применения.

## Сценарии

- Создатель получает отдельную ссылку ведущего с секретом во фрагменте URL. Гостям копируется ссылка без секрета.
- Встреча: каждый участник может говорить и показывать экран. Вебинар: зрители смотрят, пишут в чат, поднимают руку; ведущий приглашает на сцену.
- Пометки поверх текущей демонстрации синхронизируются через LiveKit и D1. Изначально рисовать могут все; ведущий может запретить пометки отдельному участнику или всем сразу, а также очистить холст.
- Для показа вкладки ведущий сначала открывает окно ведущего, затем выбирает вкладку. В плавающем окне есть мини-превью для пометок, участники и чат. Замена фона камеры доступна до входа и во время звонка; изображение остаётся на устройстве пользователя.
- Кнопка «Закончить конференцию» завершает комнату для всех участников.
- Ведущий вручную запускает запись. Через отдельную ссылку готовое видео доступно любому, у кого есть эта ссылка, до истечения 30 дней.

Проверяйте демонстрацию и инструменты пометок в настольном Chrome или Edge по HTTPS. В мобильном браузере поддерживаются просмотр, чат и поднятие руки.
